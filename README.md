# Library

Papers by Oumuamua Labs on the systems it builds.

Each paper/note lives in `<project>/<slug>/`, with its PDF named after the folder and a README holding its abstract,
its revisions and a BibTeX entry. Paths never move. A new revision replaces the PDF at the same path, and the
paper's README lists every revision.

unless its folder holds a LICENSE of its own.
